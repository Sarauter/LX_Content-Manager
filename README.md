# LADX — Contenido Web

Herramienta de revisión del contenido web, para uso interno del equipo.

- **`index.html`** — la herramienta interactiva: contenido sección por sección, con botones de aprobar/comentar, descarga de comentarios/contenido, y el estado de avance del desarrollo web. Publicada vía GitHub Pages.

Este repositorio es público. No incluye contratos, brand book ni otro material confidencial del proyecto — solo el contenido de la web en revisión.
