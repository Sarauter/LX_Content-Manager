# LADX — Contenido Web

Herramienta de revisión del contenido web de LADX (ladx.net), para uso interno del equipo.

- **`index.html`** — la herramienta interactiva: contenido sección por sección, con botones de aprobar/comentar, descarga de comentarios/contenido, y el estado de avance del desarrollo web. Publicada vía GitHub Pages, protegida con usuario y contraseña.
- **`LADX_Contenido_Web_SEO-GEO-AEO.md`** — el documento de trabajo en texto plano, espejo del contenido de `index.html`.

Este repositorio es privado y de acceso restringido. No incluye contratos, brand book ni otro material confidencial del proyecto — solo el contenido de la web en revisión.
